# Prosody XMPP Server Add-on

Self-hosted XMPP server for Home Assistant OS.

## Installation

1. Add this repository to your HAOS Add-on Store
2. Install "Prosody XMPP Server"
3. Configure domain, admin username and password
4. Start the add-on

## Configuration

| Option | Description |
|--------|-------------|
| domain | Your XMPP domain (e.g. xmpp.xd1122x.xyz) |
| admin_user | Admin username |
| admin_password | Admin password |

## Ports

| Port | Description |
|------|-------------|
| 5222 | Client connections |
| 5269 | Server-to-server federation |
| 5280 | HTTP/WebSocket |

## XMPP Clients

- **Android**: Conversations
- **iOS**: Monal
- **Desktop**: Gajim, Thunderbird
